КАК ЗАПУСТИТЬ HTTPS

1. Установи Node.js.
2. В этой папке выполни:
   npm install
3. Запусти:
   npm start
4. Открой:
   https://localhost:3000

ВАЖНО:
Сертификат в папке cert самоподписанный и предназначен для локального теста.
Браузер может показать предупреждение о сертификате. Это нормально для такого
локального сертификата.

Для ссылки, которую можно отправить другому человеку через интернет, нужен
публичный HTTPS-домен и настоящий TLS-сертификат (например, через хостинг
или Cloudflare). Сам ZIP не делает localhost публичным.

После разрешения геолокации координаты будут видны в консоли Node.js.
Также можно открыть:
https://localhost:3000/location
